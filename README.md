# 🦠 消灭病毒 | Kill Virus

一款基于 **HTML、CSS 和 JavaScript** 开发的轻量级键盘反应小游戏。屏幕上方会不断落下带有英文字母的病毒，玩家需要迅速按下对应的键盘按键，在病毒触底之前将其消灭，挑战自己的反应速度与键盘熟练度。

本仓库提供 **单文件整合版本**：游戏界面、样式、逻辑、图片和音效均内嵌在 `index.html` 中，无需安装依赖、无需构建，打开浏览器即可游玩，也可直接部署到 GitHub Pages。

## 🎮 游戏玩法

1. 打开游戏页面，点击屏幕上的开始区域进入游戏。
2. 观察从屏幕顶部不断下落的病毒，每个病毒都标有一个英文字母（A–Z）。
3. 在键盘上按下对应字母，即可消灭病毒并获得 **1 分**。
4. 病毒接近底部时，屏幕会出现危险警告；如果有病毒落到屏幕底部，游戏结束。
5. 在失败界面点击 **重新开始**，即可清空分数并再次挑战。

> 建议使用带有实体键盘的电脑游玩。游戏主要通过键盘操作，不适合仅使用触屏的设备。

## ✨ 游戏特色

- **简单直观**：根据病毒上的字母按键即可完成操作。
- **实时挑战**：病毒持续生成并向下移动，考验反应速度。
- **即时反馈**：消灭病毒时展示动画效果并播放音效。
- **分数统计**：实时记录成功消灭的病毒数量。
- **失败重试**：病毒触底后可立即重新开始。
- **纯前端、单文件**：所有资源内嵌，无需后端服务、外部依赖或额外素材目录。

## 🚀 快速开始

### 本地运行

下载仓库中的 `index.html`，使用 Chrome、Edge、Firefox 等现代浏览器打开即可。

### 部署到 GitHub Pages

1. 在 GitHub 上创建一个新仓库，例如 `kill-virus-game`。
2. 将 `index.html` 和 `README.md` 上传至仓库根目录并提交。
3. 进入仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 下，将 **Source** 设为 **Deploy from a branch**。
5. 选择 **`main` 分支**及 **`/(root)` 目录**，点击 **Save**。
6. 等待部署完成，访问：

   ```text
   https://<你的 GitHub 用户名>.github.io/kill-virus-game/
   ```

> 如果仓库名称不同，请将网址中的 `kill-virus-game` 替换为实际仓库名。GitHub Pages 的发布需要一点时间。

## 🛠️ 技术实现

| 技术 | 用途 |
| --- | --- |
| HTML5 | 游戏页面结构与音频元素 |
| CSS3 | 游戏界面、病毒样式与视觉动画 |
| JavaScript | 病毒生成、下落更新、键盘事件、碰撞判定和计分 |
